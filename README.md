# k-Hessian 外域问题的数值与几何研究

本项目是博士研究的一部分，专注于外域 k-Hessian 方程的径向 ODE 数值求解、
几何曲率计算以及科学机器学习方法的探索。

## 目录结构
- `notebooks/`: 每日实验的 Jupyter Notebook（含详细注释）
- `src/`: 可复用的 Python 模块
- `data/`: 数值解数据
- `figures/`: 生成的图表

## 依赖
见 `requirements.txt`。主要依赖：
- Python 3.10+
- NumPy, SciPy
- Matplotlib
- Open3D (>=0.18)
- PyTorch (>=2.0)
